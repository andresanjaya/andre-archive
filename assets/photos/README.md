Place approved gallery photos here as `.jpg`, `.jpeg`, `.png`, `.webp`, or `.avif` files. Use descriptive filenames; the filename becomes the temporary gallery title until a reviewed caption is supplied.

Run `npm run sync:photos` after adding or removing files while the development server is already running. `npm run dev` and `npm run build` sync automatically before starting. Photos are copied into the public site, so remove private location metadata and confirm consent before adding them.
