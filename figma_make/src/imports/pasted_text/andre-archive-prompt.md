## Interaction model

The page should feel like an interactive spatial board.

Support:

- Dragging the background to pan around the board
- Bounded or gently infinite canvas movement
- Click-versus-drag protection
- Hover feedback on interactive objects
- Focus-visible states
- Clickable objects
- Keyboard-accessible object controls
- Small panels or popovers for each interest
- Close button and Escape behavior
- Focus restoration after closing a panel

When an object is hovered:

- Slightly lift the object
- Increase its shadow
- Reveal a small label
- Add a subtle outline or glow

When an object is clicked:

- Bring the object slightly forward
- Open a compact contextual panel
- Keep the central card and surrounding board visible if possible
- Do not navigate away to a completely separate generic page
